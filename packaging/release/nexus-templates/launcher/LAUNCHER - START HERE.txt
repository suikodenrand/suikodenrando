STARS OF DESTINY 0.14.6 - OPTIONAL WINDOWS LAUNCHER 1.0.7

This download contains the optional settings launcher, CTB tuning editor and their
self-contained Microsoft .NET 10.0.14 Windows x64 runtime. It does not install
the randomizer plugins, Suikoden Fix, ATB or BepInEx. Get the plugins-only
0.14.6 ZIP and install its external BepInEx requirement first.
https://github.com/suikodenrand/suikodenrando/releases/tag/v0.14.6

INSTALL / RUN
1. Close the game and launcher. Back up an existing launcher folder and its
   preferences/presets before replacing it. Keep Save and BepInEx/config
   backed up together before changing campaign settings.
2. Extract this ZIP into the game folder beside
   Suikoden I and II HD Remaster.exe. The resulting folder should be:
     StarsOfDestiny Launcher/StarsOfDestiny.Launcher.exe
   Keep ALL files/subfolders of StarsOfDestiny Launcher together. Do not
   copy just its EXE. No separate .NET runtime, SDK or compiler is required.
3. Run that EXE. The launcher can detect the containing game folder; if it
   asks for a location, select the folder containing the game's EXE.
4. Choose S1 or S2, seed and settings. With the game closed, use Apply settings
   or Save & launch game. Steam must be installed/available to launch normally.
   A launcher choice does not rewrite an existing campaign's seed, mapping,
   weapon or inventory policies. Use New Game to test new-campaign settings.
5. For optional S1 ATB, install the plugins-only package first (it supplies
   the reviewed dormant DLL). Turn off S1 shuffled Unites, activate the ATB
   preview, then enable it. Activation leaves fresh default ATB settings
   disabled; an already-enabled existing config is preserved. Also disable
   the legacy ShuffledTalismanPreview flag if previously enabled; see the
   plugins package's SETTINGS.txt. Never run S1 shuffled Unites and ATB
   together. ATB remains experimental and S1 only.

SUIKODEN I QUALITY OF LIFE
The four options start enabled. In the launcher, open Suikoden I > Quality of
Life to switch any option off or disable the group.
- Warehouse access adds Roc's Warehouse after Party Items once recruited.
- Shared battle items let each living active fighter use another living
  fighter's carried item. The charge comes from the owner's stack.
- Optimize equips one fighter from loose active-party gear and, after Roc
  joins, warehouse stock. Select either source or both in the launcher.
  Other fighters keep the gear they are wearing.
- The Viktor quick start matches starting companions to Tir's level with
  each companion's own stat growth.

S1 COUNT TIME BATTLE (OPTIONAL PREVIEW 0.5.2)
The battle plugin supports CTB and ATB. Both start off. With the component
installed, open Suikoden I > Battle & ATB, disable shuffled Unites and the
legacy Talisman preview, activate the component if needed, then enable the
battle preview and CTB. The CTB tuning editor opens from the same tab.
Guide: https://github.com/suikodenrand/suikodenrando/blob/v0.14.6/docs/CTB-PROTOTYPE.md

TROUBLESHOOTING
If the launcher does not open, confirm the entire folder was extracted and
has not been mixed with files from a different launcher version. If the game
loads without mods, check the separate external BepInEx installation and
BepInEx/LogOutput.log. The launcher download does not supply that loader.
Manual config editing is supported without installing or running this EXE.
Do not disable security protections to run it; report the exact file/hash and
security report URL if it is quarantined. Host approval is not guaranteed.

UPGRADE / REMOVE
Replace an existing launcher folder as a complete set after backing it up.
Preserve personalized preferences/presets as needed. To remove this optional
download, close it, back up those preferences and remove only its package-owned
files listed in StarsOfDestiny Launcher Package/FILES.txt. Keep game saves,
configs, randomizer plugins and the external BepInEx loader. Launcher removal
does not undo settings already applied. Keep any prior installer recovery.
