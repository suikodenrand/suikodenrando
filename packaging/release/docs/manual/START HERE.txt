This ZIP contains the mod and launcher. BepInEx is required and is NOT bundled.
Use the tested BepInEx 6 Unity IL2CPP Windows x64 build 697 (5362580):
https://builds.bepinex.dev/projects/bepinex_be/697/BepInEx-Unity.IL2CPP-win-x64-6.0.0-be.697%2B5362580.zip

FRESH INSTALL
1. Close the game and launcher. In Steam, right-click the game > Manage >
   Browse local files. This is the folder containing
   Suikoden I and II HD Remaster.exe and GameAssembly.dll.
2. If the game already has mods, BepInEx or a randomized campaign, read
   StarsOfDestiny Manual/MANUAL UPGRADE.txt first. Copying files manually
   does not make backups, detect conflicts or preserve settings for you.
3. Keep a backup of Save and BepInEx/config together outside the game folder
   if either exists. Back up files you are about to replace as well.
4. Download the external BepInEx ZIP above and extract its contents into the
   game folder first. Its BepInEx/core, dotnet, winhttp.dll, doorstop_config.ini
   and .doorstop_version belong beside the game EXE as supplied upstream.
5. Extract THIS mod ZIP into that same game folder. Its BepInEx folder adds
   mod plugins, default settings and dormant ATB; it is not the loader itself.
   StarsOfDestiny Launcher also goes directly beside the game EXE. Do not
   create an extra mod-named folder around either package's contents.
6. Run StarsOfDestiny Launcher/StarsOfDestiny.Launcher.exe. Choose S1 or S2,
   your seed and options. Use Apply settings or Save & launch game with the
   game closed. All launcher files and its private .NET 10 runtime must stay
   together. A separate .NET installation, compiler or SDK is not required.
7. Keep Steam and internet access available on the first modded game launch.
   BepInEx downloads Unity reference libraries and generates interop files;
   this can take several minutes. Wait for the title screen. Progress and
   errors are in BepInEx/LogOutput.log.
8. Start New Game for a new randomized campaign. Existing bound saves retain
   their saved seed, mapping, weapon and inventory policies. The F6 panel
   starts hidden; press F6 to cycle Full, Compact and Hidden for this session.

This ZIP includes the combined randomizer, launcher and Suikoden Fix, but no
BepInEx core, loader runtime, Doorstop files, setup EXE or install script.
There is no automatic backup, transaction or Start Menu shortcut.

FRESH DEFAULTS
Character Shuffle, normal opening, English dialogue replacement and shuffled
Unites are on. Protagonist shuffle, chest shuffle and ATB are off. F6 starts
Hidden with text only. First joining weapons follow Tir in S1 or Riou in S2
with seeded -3 to +3 variance, including an exact match. Existing campaigns
retain their own mapping and weapon policy.

JOINING INVENTORY AND EQUIPMENT (NEW IN 0.14.4)
Fresh default for both games: Shuffle/JoiningEquipment=MatchRole. In the
launcher, choose Original role's starting inventory under Characters.
At the replacement's first party join, it receives the original story role's
full starting inventory, including consumables such as Medicine and equipped
items. Incompatible armor and accessories use comparable equipment the
replacement can wear. The replacement keeps its own weapon identity and
rune setup. Joining weapon-level choices remain separate.
This works in Shuffle, chosen companions and random fixed-roster modes.
Replacement's starting inventory (Donor) preserves the previous behavior.
The policy and first-join history are saved with the campaign. Acquired
items, consumption and equipment changes survive later joins and reloads.
Existing campaigns without this feature's saved metadata keep Donor behavior;
upgrading does not retrofit their inventory. Changing the launcher affects
new campaigns rather than rewriting saved inventory. Keep Save and all
BepInEx/config campaign sidecars together. An S1 native test checked Meg
replacing Viktor at first join and a subsequent native save. Reload was not
observed in that test. Broader S1/S2 join, compatibility and rejoin coverage
remains limited; managed tests cover saved-policy persistence.

OPTIONAL S1 CHESTS
In Treasure, tick "Enable chest shuffle for new campaigns" and Apply settings
before starting a new game. Existing saves keep their stored chest policy.
To change one, choose checked (shuffled) or unchecked (original), Apply,
select its saved snapshot and use Reset selected save's chest settings.
The next load adopts that policy. The manager keeps a backup; acquired items
and opened chest flags stay put. On Apply, launcher 1.0.5 clears the older
global pause and resumes saved shuffles. Unticking the new-campaign option
does not pause an existing shuffled policy. S2 chest shuffle is unavailable.

OPTIONAL S1 ATB
The optional plugin is bundled dormant at
BepInEx/SuikodenRandomizer.S1BattlePreview.dll, outside the active plugins
tree. With the game closed, open S1's Battle & ATB tab in the launcher. Turn
off Enable shuffled-character Unite attacks, use Activate ATB preview, then
enable ATB, apply and relaunch. The launcher checks and copies the reviewed
DLL into plugins. Fresh default settings remain disabled after activation;
existing enabled ATB configs stay enabled. Keep only one active ATB DLL
inside plugins. To return to normal battles, disable ATB before
re-enabling shuffled Unites. S2 has no ATB implementation.
