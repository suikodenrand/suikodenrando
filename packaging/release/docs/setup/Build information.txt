This full installer includes the launcher and loader files. No separately
installed .NET runtime, SDK or compiler is required. First BepInEx startup
still downloads Unity reference libraries and generates interop; it needs
internet access. Proprietary game files and personal saves are not included.

Fresh defaults: Shuffle, normal opening, English dialogue replacement ON,
shuffled Unites ON for both games, chests OFF, optional ATB OFF, F6 Hidden.
S1 joining weapons use TirVariance; S2 joining weapons use RiouVariance.
Both use the protagonist's current weapon level with a seeded -3 to +3
offset at first join, including a possible exact match. Existing campaigns
keep their policy and earned sharpening; native Riou-policy playtesting is
pending. MatchRole and Level1 remain available for both games.
Joining inventory/equipment defaults to MatchRole in all three modes in
both games: the original role's full starting inventory, with comparable
wearable substitutes for incompatible gear. Donor retains replacement gear.
Saved campaigns keep their policy and acquired inventory; legacy campaigns
are not retrofitted. Weapon levels are configured independently. Native S1
Meg-for-Viktor first join and a subsequent save were checked; native reload
was not observed. Broader S1/S2 compatibility and rejoin playtesting remains
limited; managed tests cover saved-policy persistence.

Existing saves, settings and campaign bindings are preserved on upgrade.

See payload-manifest.json for exact file versions/hashes. The release notes
describe native-test coverage. The build-verification report records local
packaging checks and their limits. Third-party
notices and complete extracted upstream sources are bundled inside the installer
and installed in <game>/StarsOfDestiny Setup/Licenses (sources under Source).
The unused Install.cmd wrapper and duplicate support/source copies are omitted.
Restore.cmd, Restore.ps1 and their required Install.ps1 helper remain installed
in <game>/StarsOfDestiny Setup for transaction recovery.

This is the 0.14.6 release package. See the project release notes for current coverage and limitations.
