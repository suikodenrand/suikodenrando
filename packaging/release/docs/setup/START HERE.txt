STARS OF DESTINY 0.14.4 - FULL WINDOWS RELEASE
Suikoden I & II HD Remaster | Steam | Windows x64
Package revision r2 | Launcher 1.0.5

INSTALL
1. Close the game and the Stars of Destiny launcher. Keep a paired backup
   of the game's Save and BepInEx/config folders outside the game directory
   if you already have a campaign. Starting New Game may replace autosave.
2. Run the Stars of Destiny 0.14.4 setup EXE. Select the folder containing
   Suikoden I and II HD Remaster.exe and GameAssembly.dll.
3. The combined randomizer, launcher, BepInEx and Suikoden Fix are included.
   Leave "Experimental S1 ATB (installed disabled)" unchecked for standard
   turn-based battles. Select it only if you want to try the separate ATB
   preview. Installing it does not enable it.
4. Complete setup. Open the launcher from the current user's Start Menu:
   Stars of Destiny. You can also run
   <game>/StarsOfDestiny Launcher/StarsOfDestiny.Launcher.exe.
5. Choose Suikoden I or II, a seed, and your options. With the game closed,
   use Apply settings or Save & launch game. The launcher has its own .NET
   runtime; you do not need an SDK or a separately installed .NET runtime.
6. Keep Steam and an internet connection available on the first modded
   launch. BepInEx downloads Unity reference libraries and generates its
   interop files. This can take several minutes. Wait for the title screen.
7. Start New Game for a new randomized campaign. Existing randomized saves
   restore their own seed and mapping. The F6 panel starts hidden; press F6
   to show its text. F6 cycles Full, Compact and Hidden for that session.

WHAT IS INCLUDED
- Combined Suikoden I / II randomizer 0.14.4, with separate game settings.
- Seeded character Shuffle, five chosen companions, or a seeded random
  fixed roster; optional protagonist shuffle and each game's quick start.
- Supported English dialogue-name replacement in both games.
- Native shuffled-character Unite previews for both games.
- Suikoden I seeded chest shuffle, off until you enable it.
- Windows launcher 1.0.5, preset import/export and configuration backups.
- BepInEx 6 IL2CPP x64 build 697 and its private loader runtime.
- Suikoden Fix 1.5.2b and its launcher settings.
- Optional separate Suikoden I ATB Preview 0.10.1, installed disabled.
- Transaction restore tools, instructions, troubleshooting and notices.

FRESH DEFAULTS AND UPGRADES
Fresh installations use character Shuffle, the normal opening in both games,
English dialogue-name replacement, and shuffled Unites. Protagonist shuffle
and chest shuffle are off. F6 starts Hidden and uses text without a black box.
Suikoden I joining weapons use Tir's current weapon level with seeded +/-3
variance. Suikoden II now uses Riou's current weapon level with the same
seeded +/-3 variance, including a possible exact match, at first join.
Match original character and Level1 remain available for both games.
Existing settings, saved campaign bindings, saves and unrelated plugins are
preserved. Upgrades therefore retain previous settings rather than imposing
the fresh defaults. Choose Riou's weapon level +/-3 in the updated launcher's
S2 joining-weapon list for new campaigns if an older setting is retained.
Existing campaigns keep their saved policy and earned sharpening.
Not selecting ATB also preserves any existing ATB files.

SETTINGS AND SAVES
Close the game before applying settings. S1 and S2 seeds, rosters and starts
are separate. Seed, roster, quick-start, joining-weapon and inventory choices
apply to new campaigns. Saved campaigns retain their mapping and policies.
Do not delete its configuration sidecars to force new settings onto it.
Keep Save and BepInEx/config together when backing up or sharing a campaign.

JOINING INVENTORY AND EQUIPMENT (NEW IN 0.14.4)
Fresh default for both games: Shuffle/JoiningEquipment=MatchRole. In the
launcher, choose Original role's starting inventory under Characters.
At the replacement's first party join, it receives the original story role's
full starting inventory, including consumables such as Medicine and equipped
items. Incompatible armor and accessories use comparable equipment the
replacement can wear. The replacement keeps its own weapon identity and
rune setup. Joining weapon-level choices remain separate.
This works in Shuffle, chosen companions and random fixed-roster modes.
Replacement's starting inventory (Donor) preserves the previous behavior.
The policy and first-join history are saved with the campaign. Acquired
items, consumption and equipment changes survive later joins and reloads.
Existing campaigns without this feature's saved metadata keep Donor behavior;
upgrading does not retrofit their inventory. Changing the launcher affects
new campaigns rather than rewriting saved inventory. Keep Save and all
BepInEx/config campaign sidecars together. An S1 native test checked Meg
replacing Viktor at first join and a subsequent native save. Reload was not
observed in that test. Broader S1/S2 join, compatibility and rejoin coverage
remains limited; managed tests cover saved-policy persistence.

OPTIONAL S1 CHESTS
In Treasure, tick "Enable chest shuffle for new campaigns" and Apply settings
before starting a new game. Existing saves keep their stored chest policy.
To change one, choose checked (shuffled) or unchecked (original), Apply,
select its saved snapshot and use Reset selected save's chest settings.
The next load adopts that policy. The manager keeps a backup; acquired items
and opened chest flags stay put. On Apply, launcher 1.0.5 clears the older
global pause and resumes saved shuffles. Unticking the new-campaign option
does not pause an existing shuffled policy. S2 chest shuffle is unavailable.

OPTIONAL S1 ATB
Select "Experimental S1 ATB (installed disabled)" during setup. In the
launcher's Battle & ATB tab, turn off "Enable shuffled-character Unite
attacks" for S1 before enabling ATB preview, then apply
and relaunch. The two previews cannot run together. ATB uses native command
menus, targeting and SPD bars. To return to standard battles, turn ATB off;
you may then re-enable shuffled Unites. S2 has no ATB implementation.

SUPPORT AND RESTORE
Setup prints a transaction backup path under <game>/SRR-Backups/FullPreview-*.
Keep that path. The Start Menu support shortcut opens StarsOfDestiny Setup in
the game directory. Read Troubleshooting.txt there, or run Restore.cmd to
undo one installation transaction while the game and launcher are closed.
Restore does not rewind gameplay or undo later changes to settings.
License notices and complete extracted upstream sources are bundled inside
the installer and installed in <game>/StarsOfDestiny Setup/Licenses, with
sources under Source. The outer download omits duplicate support files.

TEST COVERAGE AND LIMITS
This is the 0.14.4 release package. Representative Unite attacks, shuffled parties,
save/load transitions and the F6 presentation have been tested in-game; every
campaign, Unite recipe and scripted encounter has not been played through.
S1 chest shuffle and optional ATB remain experimental. See the release notes
for native-test coverage and the package manifest for exact file hashes.
The build-verification report records packaging checks and their limits.
Riou-based joining weapons have managed regression coverage; native first-join
playtesting of this new option is still pending.
