# Stars of Destiny Launcher 1.0.8

Select **Join our Discord** in the upper-right corner of the launcher to open the invitation in your default browser. The link is available on every tab for both games and works before you choose a game folder. You can also focus the link with Tab and press Enter. [Stars of Destiny - Randomizer on Discord](https://discord.gg/NbjPpcG3Cb)

## Get the update

New players get launcher 1.0.8 with the **0.14.6-r2 Windows installer**. The revised manual ZIP and S1 CTB preview ZIP also include it. [Windows downloads](https://github.com/suikodenrand/suikodenrando/releases/tag/v0.14.6)

If you already have 0.14.6 installed, close the launcher and CTB editor, then back up your existing `StarsOfDestiny Launcher` folder. Extract the complete launcher folder from the standalone ZIP beside the game executable. Copy your backed-up `launcher-preferences.json` into the replacement folder if you use custom launcher preferences. [Download launcher 1.0.8](https://github.com/suikodenrand/suikodenrando/releases/download/v0.14.6/Stars-of-Destiny-Launcher-1.0.8-Windows.zip)
