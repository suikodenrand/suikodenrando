# Stars of Destiny Launcher 1.0.7

Launcher 1.0.7 accompanies Stars of Destiny 0.14.6. The setup and manual packages include the launcher. For a plugins-only installation, extract the standalone launcher ZIP beside the game executable.

## Suikoden I quality of life

Select **Suikoden I → Quality of Life**. Under **Suikoden I inventory and quick start**, choose the features you want, then use **Apply settings** with the game closed. All four are on by default. **Disable all four** and **Enable all four** change the group together.

| Option | When enabled |
| --- | --- |
| Roc’s Warehouse | Open the warehouse from the field Items menu once Roc has joined. |
| Shared battle items | Use battle items carried by any living member of the active party. The carrier spends the charge. |
| Optimize equipment | Select Optimize for a fighter in Equipment. Change its gear sources with Left and Right in game. |
| Match starting companions to Tir | For a new Viktor quick start, raise the two starting companions to Tir’s checkpoint level using their own growth. |

Turning a feature off changes what happens the next time you use that menu or start a campaign. Previously earned levels, equipped gear, and inventory are part of your save. The four preferences also travel with launcher presets.

## Optional S1 CTB preview

Select **Suikoden I → Battle & ATB**. If the component is dormant, choose **Activate ATB / CTB preview**. Clear **Enable shuffled-character Unite attacks** for S1 and turn off the legacy Talisman preview in Advanced if you enabled it previously. Check **Enable battle preview component** and **Enable CTB (overrides ATB)**, then apply. Break and reserve Rally have separate switches. **Open CTB tuning editor** opens the editor for the selected installation.

For standard turn-based combat, clear **Enable CTB (overrides ATB)** and **Enable battle preview component**, then apply. The S1 inventory and quick-start preferences are independent of the battle mode. [Release downloads](https://github.com/suikodenrand/suikodenrando/releases/tag/v0.14.6)
